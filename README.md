# Neuzeit

Klickbarer Website-Prototyp (Onepager) für **Neuzeit**, eine geplante Unternehmensberatung für den Mittelstand. Kein Livegang: Der Prototyp zeigt, wie Neuzeit als modernes Beratungsunternehmen wirken könnte. Fehlende Inhalte sind sichtbar als [Platzhalter] markiert.

**Online ansehen:** https://yannickoderso.github.io/Neuzeit/ (über GitHub Pages)

## Inhalt

- `neuzeit-prototyp/`: Website mit `index.html`, `styles.css` und `main.js`, ohne Framework und ohne Build-Schritt
- `neuzeit-prototyp/logo/`: Logo in allen Varianten, Favicon, Profilbild und `LOGO.md` mit den Regeln
- `neuzeit-prototyp/fonts/`: Fraunces und Manrope, selbst ausgeliefert (SIL Open Font License)

## Lokal öffnen

`neuzeit-prototyp/index.html` im Browser öffnen, per Doppelklick oder durch Ziehen ins Browserfenster. Einen Server braucht es nicht.
